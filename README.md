# SHODH — AI-Assisted Specification and Workflow Reviewer

An engineered system that verifies whether structured specifications, workflow graphs, and Python routing scripts faithfully implement written business requirements, changes, and policies.

## Key Capabilities
- **Deterministic Semantic Verification**: Ast-level Python inspection, DAG graph validation, and requirement-to-spec coverage.
- **Counterexample Generation**: Concrete ticket inputs proving disagreements.
- **Approval & Change Conflict Resolution**: Version-aware policy derivation and contradictory approval record detection.
- **Bounded LLM Assistance**: Model-assisted interpretation and explanation with strict schema validation, evidence citations, and failure handling.
